  \item We parallelize the algorithm and present $5$ versions that keep optimizing. We compare the speedup performance with the baseline model. We consider the following $5$ models: 


\begin{itemize} 
    \item \textbf{GPU Naive:} An embarrassingly parallel implementation on CUDA by blocks (see \texttt{heat1.cu}). 
    \item \textbf{GPU Shared Memory (V1):} We use \texttt{\_\_shared\_\_} memory to allocate the halo pixels that are not inside the block in the computation (see \texttt{heat2.cu} and \texttt{heat3.cu}).  
    \item \textbf{GPU V2 (Constant + No Modulo):} Relocates the kernel to \texttt{\_\_constant\_\_} memory for hardware broadcasting and replaces expensive modulo (\texttt{\%}) operations with \texttt{if/else} bounds checking to reduce arithmetic costs.
    \item \textbf{GPU V3 (FP32):} Transitions from 64-bit to 32-bit precision. By this, we unlock the GPU's dominant FP32 cores and doubles effective memory bandwidth.
    \item \textbf{GPU V4 (Fused + Texture):} Combines multiple memory accesses into a single operation and utilizes texture memory for spatial locality, further enhancing performance.
\end{itemize}
